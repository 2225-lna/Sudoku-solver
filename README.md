# Sudoku-solver
1. Project Description
For our project we implemented a 9x9 Sudoku solver using Basic Backtracking and Backtracking with Minimum Remaining Values (MRV).The purpose of the project was to solve sudoku puzzles using the two algorithms (MRV and basic Backtracking) and compare them based on execution time and number of search nodes.

2.Setup Instructions	
1.Upload the testing_sudoku.py file.
2.import the other python files included in the README.
3. Run the testing_sudoku.py
following these step will allow the program to run successfully.

3.input Format
The program accepts the puzzle as a 2-D python list contains only 9 rows and 9 columns. empty cells are represented as 0. no duplicates are allowed in any of the rows ,columns ,and 3X3 boxes. 

4.How to run
open google collab and create a new notebook. after creating the new note new notebook upload the given files. enter in the code cell the command(%run testing_sudoku.py). run the cell or run all to execute.
